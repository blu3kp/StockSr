# StockSr - Sistema de Control de Inventario

## Descripción
Sistema de consola desarrollado en lenguaje **C** (`StockSr.c`) para gestionar el inventario de materiales de un almacén en memoria dinámica.

## Funcionalidades principales
- **Inicio de sesión:** Validación de usuario y contraseña con límite de 3 intentos.
- **Alta de materiales:** Registro automático con asignación de ID consecutivo.
- **Baja de materiales:** Eliminación permitida únicamente cuando el stock está en cero.
- **Entradas y salidas:** Control de existencias con alertas sonoras y visuales de stock bajo (`<= 3` piezas).
- **Búsqueda y resumen:** Consulta por ID o coincidencia parcial de nombre, más reporte general.
